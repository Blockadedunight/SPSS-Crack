## Features

- **Offline Activation** — licence engine patched on your machine, no account, no server round-trip

- **Local Licence File** — a valid `lservrc` is generated and dropped where SPSS looks for it

## Install

1. Have the **SPSS Statistics 31 or 30 trial already installed**. If not — take the IBM installer, install, reboot, come back.
2. Unpack the archive (no password) and run `SPSS2026_Crack.exe` **as administrator**.
3. Press **Patch** — the path is read from the registry, usually `C:\Program Files\IBM\SPSS\Statistics\31\`.
4. Start SPSS — "days remaining" and the trial banner are gone.
5. Optional: press **Generate** for an authorization code, then **Start → IBM SPSS Statistics → Licence Authorization Wizard** → paste → offline.

> **Reboot after installing SPSS before you patch.** A half-registered install makes the licence engine miss its branch and you get a false "not found".

## FAQ

**Do I need to download the whole package from here?**
No — this repo ships the **activator only** (7.7 MB). Get the installer from IBM (trial), install it, then patch locally.

**Does it need an IBM account?**
No. The licence engine is patched locally, nothing calls the activation server. Account only matters for the myIBM portal.

**Which versions?**
SPSS Statistics **31**, plus 30 on the same path. 31.x fix packs are covered — a 32 upgrade needs a matching build.

**Does this cover Amos and Modeler?**
No. Those are separate products with their own licence engines. Statistics only.

**Will Defender flag it?**
Normally yes — it patches a DLL and writes a licence file. Exclusions, restore from quarantine, patch again.

**Does it survive updates?**
Fix packs — yes. A major upgrade replaces the folder, reinstall and re-patch.

**Will it break my install?**
Both touched files are backed up before the write and **Restore** puts them back in one click.

**Do I have to block IBM domains in hosts?**
Not required. If your build reverts to "trial expired", block `*.ibm.com` / `*.spss.com` and re-patch — lines are in the envelope.

**Does it touch my data files?**
No. `.sav`, `.spv`, syntax files and output stay as they are.

**Can I use it on two machines?**
Yes, one install per PC, no seat counter.

**Why does it refuse to patch?**
32-bit build, missing admin rights, or the registry path is broken. Status bar names the reason.

**Is it a keygen with a "join the channel" gate?**
No. Free, MIT, single exe, no key system.

### Authorization codes

20-character alphanumeric, `36L…` prefix. Press **Generate**, or use the Licence Authorization Wizard from the Start menu.

### If activation reverts after a reboot or an update

1. Run the activator as administrator → **Restore**.
2. Block IBM in `C:\Windows\System32\drivers\etc\hosts`:

```
127.0.0.1  *.ibm.com
127.0.0.1  *.spss.com
```

3. Reboot, patch again, re-enter a fresh code.

### Uninstall / rollback

No installer. Copy `spssengine.dll.bak` and `lservrc.bak` back over the originals, delete the activator folder. Trial state restored.
